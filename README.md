# RedVerse MediaHub 🐉🎛️

A standalone browser-based audiovisual playground with audio-reactive FFT effects, independent chromatic palettes, lyric overlays and recording.

## Features

- Reactive ring, frequency bars and lightning effects
- Separate customizable colour palettes and visualizer sliders
- Audio playlist and track metadata
- Timed lyric support for LRC, SRT and VTT
- Canvas-based video recording

## Getting started

Download or open `index.html` in a modern desktop browser. Load your own music and optionally add a matching timed lyrics file. No build system or server is required for local use.

## Status

Experimental. Browser playback, metadata parsing, seeking and recording should be tested on your device before relying on exports. Respect the rights of audio and background assets when publishing recordings.
